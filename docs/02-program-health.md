# Program Health

This document describes how program leaders monitor overall delivery health using status indicators, milestone tracking, and risk visibility.

Program health provides leadership with a clear understanding of whether a program is progressing as expected.

## Health Indicators

Programs commonly track the following indicators:

- milestone progress  
- dependency readiness  
- risk severity  
- resource availability  
- stakeholder alignment  

## Status Categories

### Green
Program is progressing as planned with no significant risks.

### Yellow
Program has emerging risks or delays that require attention.

### Red
Program faces major risks or blockers requiring leadership intervention.

## Health Reporting

Program health updates should be:

- concise  
- consistent  
- action-oriented  

Leaders should quickly understand:

- current status  
- major risks  
- decisions required  
- upcoming milestones
